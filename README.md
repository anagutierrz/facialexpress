# Facial Express — Demo web

Sube todos estos archivos directamente a la raíz de tu repositorio de GitHub, al mismo nivel que index.html. No requiere carpetas, instalación ni compilación.

Para abrirlo localmente, abre index.html en tu navegador.

Si lo publicas en GitHub Pages: Settings → Pages → Deploy from a branch → main → / (root) → Save.

Incluye el selector interactivo, las cuatro líneas de cuidado y las animaciones. Las solicitudes de evaluación son simuladas: no se envían datos ni se crean citas reales.
